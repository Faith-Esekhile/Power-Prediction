# Power-Prediction

**Problem**

Identify what factors influence power efficiency across systems to :

Identify inefficiencies in energy use,

Optimize performance of equipment, or

Forecast power needs accurately.

**Solution**

This project analyzes and visualizes key features affecting power consumption to support data-driven energy optimization.

Key outcomes:

Explored correlations between sensor readings and energy efficiency.

Identified which parameters most impact power output

Provided clear visuals (heatmaps, min–max analysis, time trends) to guide operational decisions

Enables the energy management team to understand system performance, prioritize impactful factors, and design strategies to reduce energy waste.

**Next Steps**

Develop a predictive model for real-time power efficiency forecasting

Create a dashboard for monitoring sensor performance over time

Expand dataset to include environmental and maintenance variables for better predictions
